## v2.1 — Nowcasting и точность (Q4 2026)
- **Экстраполяция последних наблюдений**: blending fresh-obs ↔ model
  (вес наблюдения падает по возрасту: 0→30 мин) — «костяк nowcasting»
- Радар осадков (RainViewer API, бесплатный) + движение фронтов по ячейкам
- Nowcast-виджет «дождь начнётся через N минут» (адвекция по градиенту)
- Push-уведомления по геозонам: «через час порывы >12 м/с» (WorkManager + серверные сигналы при pull)
- Виджет на главный экран Android (Glance)
- Улучшение валидации наблюдений: кросс-сравнение с моделью (Barnes-подобный вес)

## v2.2 — Мультимодельный ансамбль на сервере
- Подключение GFS/ECMWF/ICON через Open-Meteo (модели уже в forecast_sources)
- Серверный ансамбль: взвешенное среднее моделей + bias по ячейкам
- Вероятностные прогнозы: p10/p50/p90 по разбросу моделей
- Калибровка вероятности осадков (reliability diagram на накопленных парах)
- Карта точности по регионам (админка + клиент)
- Экспорт CSV/API для интеграций (по api_key, rate limit повышенный)

## v3.0 — Платформа
- VPS/Docker-версия сервера (тот же код, PHP-FPM + Nginx + Redis rate limit)
- iOS-клиент (SwiftUI) поверх того же API
- PWA-версия сайта (тот же REST API)
- ML-модель коррекции (градиентный бустинг на фичах: час, сезон, ячейка,
  источник) — обучение оффлайн, инференс — таблица коэффициентов
- Рынок исторических данных: агрегаты 0.1° за годы (тепловые карты климата)
- Монетизация: Pro-подписка (пороговые алерты без лимитов, экспорт),
  бесплатный ядро-функционал навсегда
- SOC2-подобный аудит: расширенный audit_log, двойное хранение бэкапов
